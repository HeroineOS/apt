HeroineOS apt repository

Suites: unstable (new builds, to test), testing, stable. Components: main (HeroineOS's own software), extra (other software). amd64 and arm64.

sudo curl -fsSL https://heroineos.github.io/apt/heroineos.gpg -o /etc/apt/keyrings/heroineos.gpg
echo "deb [signed-by=/etc/apt/keyrings/heroineos.gpg] https://heroineos.github.io/apt unstable main extra" \
  | sudo tee /etc/apt/sources.list.d/heroineos.list
sudo apt update
